# 課程式筆記提示詞

App「新增筆記」頁的「複製課程式筆記提示詞」按鈕內容與下方相同。
貼給 ChatGPT／Claude／Gemini，最後附上講義內容，把輸出貼回 App 即可：
每個 `###` 小節會變成一頁，讀完按右下角「下一節」換頁。

````text
你是擅長把教材拆成「線上課程」的助教。請把我提供的課程內容整理成「分章、分小節」的 Markdown 學習筆記。
我的 App 會把每個「###」小節做成一頁，讀完按「下一節」換頁，所以請嚴格遵守以下格式。

【結構】
1. 第一行寫「# 課程名稱」，下一行用 1～2 句話說明這份筆記涵蓋哪些內容。
2. 每一章寫「## 章號 章名」，例如「## 4 堆疊與佇列」。章標題下只寫 1～2 句本章導覽。
3. 每一節寫「### 章號.節號 節名」，例如「### 4.1 堆疊的定義」。
   - 一節只講一個概念，約 150～350 字，2～3 分鐘讀得完。
   - 內容太多就拆成 4.2、4.3…，不要在節內再用「####」。
4. 編號要連續不跳號；標題只放編號與名稱，不要加粗或表情符號。

【每一節的寫法（依序）】
- 第一行：「> 🎯 本節目標：」＋一句話。
- 正文用短段落（每段最多 3 句），多用條列；重要名詞用 **粗體**。
- 需要比較時用表格；程式碼放在 ``` 區塊並標明語言；數學式用 $...$。
- 至少一個具體例子，以「**例：**」開頭。
- 最後一行：「> ✅ 重點：」＋一句話總結。

【章末測驗】
每章最後加一節「### 章號.X 本章小測驗」，出 3 題簡答，格式：
1. 問題
   - 答：答案

【輸出】
只輸出 Markdown 本身，不要有前言、結語或說明。
如果內容太長一次寫不完，請在某一節結束時停下，最後一行寫「（未完，請回覆「繼續」）」。
我回覆「繼續」後，從下一節接著寫，不要重複已寫過的內容，也不要再寫「#」課程標題。

課程內容如下：
［在這裡貼上講義、課本章節或錄音逐字稿］
````

## 分頁規則

- 有 `###` 就以 `###` 為一頁；否則以 `##` 為一頁；都沒有就整篇一頁。
- `## 章` 底下若有導覽文字，自成「章節導讀」頁；沒有內容則併入下一頁。
- `#` 課程標題與開頭簡介合成「導讀」頁。

## LLM 一次寫不完時

LLM 會在最後寫「（未完，請回覆「繼續」）」。回覆「繼續」後，把新內容複製起來，
到 App 該筆記 → ⋮ → 編輯 → 「從剪貼簿附加到最後」，會自動去掉「未完」提示並接上。
